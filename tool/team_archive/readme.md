# «Норма рядом» — архив для команды

Мобильное приложение-гид по питанию вне дома. Пользователь задаёт свою норму КБЖУ, приложение подбирает, что заказать в заведениях рядом, чтобы в неё уложиться, показывает, насколько можно доверять цифрам, и записывает приём пищи в дневник.

**Репозиторий:** https://github.com/ilzen6/norma-ryadom (открытый)

## Как попробовать

- **Android без сервера:** APK лежит в папке `0. Приложение для Android` (он же — `norma-ryadom-offline.apk` в https://github.com/ilzen6/norma-ryadom/releases). В ней встроенный каталог, и вы «находитесь» в Москва-Сити.
- **Android с сервером на своём компьютере:** `norma-ryadom-demo.apk` из того же раздела. Инструкция в `4. Документация из репозитория/install-phone.md`.
- **iPhone:** веб-версия демо открывается по ссылке, которую даёт владелец проекта.
- **Из исходников:** раздел «Развёртывание и запуск» в описании проекта и `README.md` в репозитории.

## Что проверить при тестировании

1. Онбординг: возраст, рост, вес, активность, цель → норма с пояснением расчёта. Норму нельзя задать ниже безопасного минимума.
2. «Что взять»: выбрать приём пищи → «Подобрать рядом» → открыть набор → заменить блюдо → «Записать в дневник».
3. Карта: точки и кластеры, список «Заведения рядом» (свайп вверх — на весь экран), «Показать все», выбор города и района.
4. Экран заведения: меню с пометками «подходит / можно, но… / не подходит», источник и дата данных, «Цифры не совпадают», «Заведение закрыто или переехало?», фото меню.
5. Профиль: исключения продуктов, район, тёмная тема (по системе), удаление данных.
