## Как пересобрать

Исходные файлы (сохранённые страницы, ответы API, PDF) кладутся в `menus-inbox/<сеть>/`; папка не попадает в git.

| Сеть | Что сохранить | Команда |
|---|---|---|
| Cofix | страницу сайта заказа как `cofix-msk.html` | `python3 tool/menus/cofix.py <папка>` |
| Бургер Кинг | PDF приложения к прейскуранту | `python3 tool/menus/burger_king.py <файл.pdf>` (нужен `pdftotext`) |
| Крошка Картошка | страницу меню (без аргумента скрипт скачивает её сам) | `python3 tool/menus/kroska_kartoska.py [страница]` |
| Surf Coffee | ответы Tilda Store `getproductslist` | `python3 tool/menus/surf_coffee.py menus-inbox/surf-coffee` |
| Хлебник | ответы Tilda Store `getproductslist` | `python3 tool/menus/hlebnik.py menus-inbox/hlebnik` |
| Караваевы | список меню из API и карточки блюд в `details/` | `python3 tool/menus/karavaevy.py menus-inbox/kulinarnaa-lavka-brat-ev-karavaevyh` |
| Милти | главную страницу Москвы | `python3 tool/menus/milti.py <страница.html>` |
| Domino Pizza | ответ GraphQL `getMenu` для `msk` | `python3 tool/menus/domino_pizza.py <файл.json>` |
| Токио-Сити | данные `pageProps.food` страниц блюд | `python3 tool/menus/tokyo_city.py <файл.json>` |
| Папа Джонс | ответ `catalog/goods?city_id=1` | `python3 tool/menus/papa_johns.py <файл.json>` |
| Штолле | данные каталога со страницы | `python3 tool/menus/stolle.py <файл.json>` |
| Coffee Like | страницы напитков | `python3 tool/menus/coffee_like.py menus-inbox/coffee-like` |
| Prime | архив карточек блюд `pages/menu_<раздел>_<блюдо>.html` | `python3 tool/menus/prime.py <архив.tar.gz>` |
| Up Sushi | ответ `app-api/catalog` для `city=22` | `python3 tool/menus/up_sushi.py <файл.json>` |
| Cinnabon | PDF с пищевой ценностью | `python3 tool/menus/cinnabon.py <файл.pdf>` |
| Якитория | страницы разделов меню доставки как `cat_<раздел>.html` | `python3 tool/menus/yakitoriya.py menus-inbox/yakitoriya` |
| Додо Пицца | HAR-файл сайта или ответ API меню | `python3 tool/menus/dodo.py <файл>` |

После пересборки меню: `python3 tool/demo/build_demo_profile.py`, затем `cd app && dart run tool/build_demo_catalog.dart` и обновление эталона `./gradlew test --tests '*DemoComboContractTest' -PupdateContract=true`. Число доступных блюд проверяет `DemoCatalogIT`.

Рядом с каждым скриптом лежит `<сеть>.json`: адрес и дата источника, число позиций, список пропущенных строк с причиной и примечание о том, как пересчитаны значения.

## Проверки при разборе

- Калории сверяются с БЖУ (4·Б + 9·Ж + 4·У, допуск 25% или 40 ккал); строки, где цифры не сходятся или КБЖУ неполное, пропускаются и попадают в отчёт.
- Если КБЖУ дано на 100 г, оно умножается на вес порции из карточки; для напитков объём в мл принимается равным граммам.
- В каталог берётся то, что съедает один человек. Пропускаются комбо, сеты, наборы, тубусы и бенто-ланчи, торты и пироги целиком, хлеб буханками, кофе в зёрнах и в упаковке, вода. Пиццы — только размера на одного: до 25 см (Домино — 20 см, Папа Джонс — 23 см без сырного борта, Токио-Сити — не тяжелее 600 г).
- Категория (основное блюдо, гарнир, салат, напиток, десерт, соус) берётся из раздела меню сети и уточняется по первому слову названия: «Котлета «Морская»» не попадёт в напитки из-за «морс». Пирожки и круассаны с мясом считаются гарниром, а не десертом.
- Прямые кавычки в названиях заменяются на «ёлочки», чтобы CSV читался одинаково на сервере и в демо-режиме клиента.
- Отметки исключений (свинина, говядина, курица, рыба, морепродукты, молоко, глютен, яйцо, орехи, соя) строятся по составу и аллергенам, которые публикует сеть. Фразы «может содержать следы» и «производится на предприятии, где используются аллергены» не считаются. По названию блюда отметки дописываются с запасом: «сырники» — молоко и глютен, «карбонара» — свинина, молоко и яйцо, ветчина и хамон — свинина, молочные напитки — молоко.
- Штолле подписывает белки полем `fiber_amount`; это учтено в разборе.
- Cofix не публикует состав у большинства позиций, поэтому в приложении (онбординг и профиль) есть предупреждение: при аллергии состав уточняется у персонала.

## Сети без меню в демо-каталоге

| Сеть | Почему нет данных |
|---|---|
| Вкусно — и точка, Rostic's | сайты отвечают 403 «Access Blocked» на зарубежные адреса |
| Додо Пицца, Теремок, Тануки | защита от ботов или блокировка зарубежных адресов; Додо можно добавить из HAR-файла скриптом `dodo.py` |
| Суши Wok, Дринкит | капча и защита от ботов |
| Шоколадница | на сайте только калории, без белков, жиров и углеводов |
| Цех85 | из карточек нельзя понять, дано КБЖУ на 100 г или на порцию |
| Baggins Coffee | калории на сайте не сходятся с БЖУ у большинства позиций |
| One Plus Coffee, Stars Coffee, Стардогс | КБЖУ на сайте не публикуется |

Такие заведения видны на карте по запросу «показать все» с пометкой «нет данных о меню». Меню добавляется через админку (CSV или фото меню с модерацией).
