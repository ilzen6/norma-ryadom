# Установка на телефон для проверки

## iPhone и любой телефон — демо-версия в браузере

Без сервера и без установки: веб-версия приложения со встроенным демо-каталогом. Подбор, пометки блюд и замены считаются прямо в браузере по тем же правилам, что и на сервере. Совпадение проверяет тест `test/data/demo/demo_contract_test.dart` по эталону `contract/combo-cases.json`, который записывает серверный тест `DemoComboContractTest`. Вы «находитесь» в Москва-Сити, профиль и дневник хранятся в браузере.

1. Откройте ссылку на демо-версию в Safari.
2. «Поделиться» → «На экран „Домой“» — приложение появится на рабочем столе.

Собрать демо-версию самому:
```bash
cd app && flutter build web --release --no-web-resources-cdn --dart-define=DEMO_SERVER=true --dart-define=TILE_URL_TEMPLATE=
```
Каталог для неё пересобирается из CSV сервера командой `dart run tool/build_demo_catalog.dart`.

## Android с настоящим сервером

Приложению нужен сервер с меню заведений. Для проверки его проще всего запустить на своём компьютере. Телефон подключается к нему по той же сети Wi‑Fi.

### 1. Сервер на компьютере

Нужен Docker (на Windows и macOS — Docker Desktop).

1. Скачайте репозиторий (`git clone` или Code → Download ZIP) и откройте терминал в его папке.
2. Создайте файл `.env` из `.env.example` и заполните:
   - `DB_PASSWORD`, `S3_ACCESS_KEY`, `S3_SECRET_KEY`, `REPORTER_KEY` — любые длинные случайные строки;
   - `ADMIN_PASSWORD_HASH` — bcrypt-хеш пароля админки, его выдаст Docker (замените `мой-пароль`):
     ```bash
     docker run --rm httpd:2.4-alpine htpasswd -nbBC 10 "" мой-пароль
     ```
     Из ответа возьмите всё после двоеточия и запишите в одинарных кавычках: `ADMIN_PASSWORD_HASH='$2y$10$…'`;
   - `SERVER_BIND=0.0.0.0` — иначе сервер будет доступен только с самого компьютера.
3. Соберите сервер (JDK ставить не нужно — сборка идёт в контейнере) и запустите:
   ```bash
   docker run --rm -v "$PWD/server":/src -w /src eclipse-temurin:21-jdk ./gradlew --no-daemon bootJar
   docker compose up -d --build --wait
   ```
   В PowerShell вместо `$PWD` пишите `${PWD}`.
4. Узнайте адрес компьютера в локальной сети: Windows — `ipconfig` (строка «IPv4-адрес»), macOS — `ipconfig getifaddr en0`, Linux — `hostname -I`. Например, `192.168.1.5`.
5. Проверьте с телефона в браузере: `http://192.168.1.5:8080/actuator/health` должен показать ответ со словом `UP`. Если не открывается, разрешите порт 8080 в брандмауэре компьютера.

### 2. Приложение на телефоне

1. На телефоне откройте страницу репозитория → Releases → последняя «Демо-сборка» → скачайте `norma-ryadom-demo.apk`.
2. Откройте файл и разрешите установку из этого источника. Перед установкой новой сборки удалите старую: каждая сборка подписана своим отладочным ключом.
3. Пройдите онбординг. Затем Профиль → «Сервер» → введите `http://192.168.1.5:8080` (ваш адрес) → «Проверить и сохранить».

Демо-сборка («Норма рядом · демо») разрешает обычный HTTP, чтобы работать с компьютером в локальной сети. Обычная сборка принимает только адреса с `https://`.

### 3. Что проверить

Демо-каталог — реальные заведения Москвы, области и Петербурга; КБЖУ есть у Cofix, Бургер Кинга и Крошки Картошки. Если вы не в Москве, в Профиле выключите геолокацию и выберите район, например «Москва-Сити»: подбор пойдёт от него.

Сценарий проверки — `demo.md`: норма → подбор рядом → замена блюда → дневник → карта → заведение → жалоба → фото меню. Фото и жалобы видны в админке на компьютере: http://localhost:8080/admin.

### Если что-то не так

| Симптом | Что сделать |
|---|---|
| «Нет связи с сервером» | Телефон и компьютер в одной сети Wi‑Fi? Открывается ли `/actuator/health` в браузере телефона? |
| «Рядом нет наборов» | Выключите геолокацию в профиле и выберите район Москвы |
| Приложение не ставится поверх старого | Удалите старую версию и установите заново |
| Карта без улиц | Улицы и здания встроены для Москвы, области и Санкт-Петербурга — переключение кнопкой с названием города; в остальной России видна обзорная карта страны |
