## Сквозные сценарии

1. **Сценарий защиты** (раздел 16 документа), `e2e/tests/app.demo-scenario.spec.ts`:
   онбординг 25 лет / 165 см / 62 кг / умеренная активность / похудение → норма 1800 ккал с объяснением → «без свинины» → разрешение геолокации → обед ≈ 630 ккал → «Подобрать рядом» (≥ 3 варианта, без свинины) → набор с отклонениями → замена блюда с пересчётом → «Записать в дневник» → остаток уменьшился → карта с цветными точками → заведение со значками достоверности → «Собрать обед здесь» → жалоба на цифры → загрузка фото меню из галереи.
2. **Админка**, `e2e/tests/admin.moderation.spec.ts`: вход и отказ при неверном пароле; создание сети, ошибки CSV построчно, импорт меню и точек; фото меню проходит OCR в контейнере, модератор переносит блюда, они появляются в API с уровнем B; повторная жалоба того же человека не считается, жалобы трёх разных людей убирают блюдо из выдачи, модератор исправляет цифры, блюдо возвращается.
   Данные админских тестов не пересекаются со сценарием приложения: тестовая сеть — в Санкт-Петербурге, фото и жалобы — на точку «Пицца Квадрат, Курская» и блюдо со свининой, которое сценарий исключает.
   Стенд E2E имитирует обратный прокси: `TRUSTED_PROXIES_REGEX` разрешает `X-Forwarded-For` только из сети Docker, по умолчанию заголовок не доверяется (это проверяет `HttpEdgeIT`).

Скриншоты каждого шага — `docs/screenshots/`.

## Дефекты, найденные тестами и исправленные

| Где нашли | Дефект | Исправление |
|---|---|---|
| Интеграционный тест | Кэш лучших наборов фактически не работал: не было `@EnableCaching` | Добавлена `CachingConfiguration`, тест проверяет наполнение кэша и сброс по версии меню |
| Интеграционный тест | Фото в S3 сохранялось испорченным: AWS SDK по умолчанию шлёт тело в `aws-chunked` с контрольными суммами | Отключены chunked encoding и обязательные контрольные суммы в клиенте S3 |
| Интеграционный тест | tess4j 5.20 несовместим с Leptonica 1.82 из Ubuntu 24.04 | tess4j 5.4.0, в образе и CI — ссылки на системные библиотеки |
| Интеграционный тест | При ошибке тела запроса с валидацией метода имя поля терялось (`body` вместо `reason`) | Обработчик читает ошибки из `Errors`, а не только `BindingResult` |
| Ручная проверка API | Ошибка конвертации параметра раскрывала имена Java-классов | Для ошибок привязки отдаётся нейтральное «имеет неверное значение» |
| E2E | Загрузка фото обрывалась молча: действие держало `Ref` автоудаляемого провайдера и обращалось к нему после `await` | Действия получают зависимости явно; обновления состояния после `await` проверяют `ref.mounted` |
| E2E | Проверки набора и его замены считались от разных целей (округлённой и точной) | Выбранный набор и замены используют `appliedTarget` поиска |
| Виджет-тест | Переполнение строки «Достоверность набора» на узких экранах | `Row` заменён на `Wrap` |
| Виджет-тест | После сохранения профиля экран редактирования не закрывался: каждое сохранение перезапускало роутер | Роутер уведомляется только при смене «есть профиль / нет профиля» |
| Виджет-тест | Лист «Цель приёма пищи» открывался под плавающей панелью вкладок, кнопка «Сохранить» не нажималась | Лист открывается в корневом навигаторе |
| Виджет-тест | При шрифте ×2 переполнялись остаток БЖУ, переключатель приёмов пищи, строка калорий карточки, панель карты и строки прогресса дневника | Гибкие `Wrap`/`Flexible` и масштабирование подписей вместо фиксированных строк |
| E2E (скриншоты) | Заглавные буквы над заголовками озвучивались по буквам | У надписи есть исходный текст для озвучки |
| Независимое ревью | Карта при каждом нажатии на точку заново проецировала 20 тысяч зданий и дорог, а при обновлении списка пересоздавалась целиком | Слои подложки создаются один раз на тему, карта остаётся на месте при перезагрузке списка, подложка разбирается вне UI-потока, мелкие дороги появляются с 14-го масштаба |
| Аудит вёрстки | На ширине 320 dp «цена не указана» сжимала название блюда до буквы в строке | Название и цена делят строку 5:2, цена переносится |
| Аудит вёрстки | Выпадающий список района в профиле вылезал за край на 40 dp и наезжал на стрелку | Список растягивается по ширине и сокращает длинное название |
| Аудит вёрстки | Подписи станций метро прятались под точками заведений | Подпись показывается, только если не пересекается с точкой, кластером или другой подписью |
| Аудит вёрстки | Кружки-кластеры и точки сливались для экранного диктора в подпись карты | У каждой точки и кластера свой узел доступности с действием «нажать» |
| Независимое ревью | Значок блюда искался внутри слов («шоколад» → напиток) | Совпадение только с начала слова |
| Независимое ревью | Анимации не учитывали системную настройку «уменьшить движение», а прокрутка к заменам срабатывала при каждом пересоздании блока | Анимации выключаются по настройке, прокрутка — только при появлении вариантов |
| CI (GitHub Actions) | Хранилище в Docker не проходило проверку готовности: на раннере `localhost` в контейнере — это IPv6 `::1`, а SeaweedFS слушает только IPv4 | Проверки готовности обращаются к `127.0.0.1`; при падении E2E скрипт печатает логи контейнеров в лог CI |
| Ручная проверка на телефоне | Подпись «Или выберите район» в профиле наезжала на поле и соседний переключатель | Выпадающий список заменён полем, которое открывает шторку с поиском и группами «Москва / Московская область / Санкт-Петербург»; аудит вёрстки проверяет и шторку |
| Аудит вёрстки | Под развёрнутым на весь экран списком оставалась плашка города, доступная диктору | При полном списке плашка скрывается, карта исключается из озвучки |
| Аудит вёрстки | Число «17 374» в настройках переносилось между «17» и «374» | Неразрывный пробел |
| E2E | Первые символы в полях онбординга терялись («165» → «65»), кнопка «Далее» оставалась неактивной: Playwright печатал раньше, чем поле получало фокус | Ввод ждёт фокуса поля и проверяет итоговое значение; при обычной скорости набора потерь нет |
| Независимое ревью | Одна неудачная подгрузка при сдвиге карты заменяла карту экраном ошибки и сбрасывала положение | Показывается последний удачный список и плашка «Повторить»; экран ошибки — только если удачной загрузки ещё не было |
| Проверка данных | На адресах реальных заведений стояли вымышленные сети: на месте «Якитории» показывалась «Суши Нори» | Каталог из настоящих названий OSM; меню только из официальных таблиц КБЖУ сетей, остальные места — «нет данных о меню» |
| Проверка данных | Cofix не публикует состав у большинства позиций: латте и сырники проходили фильтр «Без молока», паста карбонара — «Без свинины» | Отметки по названию блюда с запасом; в онбординге и профиле — предупреждение уточнять состав при аллергии |
| Независимое ревью | Точка, закрытая модератором, возвращалась в поиск при следующей загрузке точек сети или демо-каталога (при перезапуске сервера) | Дата решения хранится в `closed_on`; вернуть точку может только источник с более поздней датой подтверждения |
| Демо-режим | Подбор рядом показывал один и тот же набор в четырёх точках одной сети | Как на сервере: от каждой сети берётся ближайшая точка |
| Независимое ревью | Сломанная пачка тайлов перезагружалась по кругу: проверка кэша выбрасывала запись о неудаче | Неудача остаётся в кэше |

| Независимое ревью | Подписи городов и метро не учитывали размер шрифта системы, выбранная точка при сильном приближении уезжала за верх экрана, поиск района различал «е» и «ё», шторка района пряталась под клавиатурой, список городов мог переполниться | Размеры подписей через `TextScaler`, сдвиг камеры в пикселях до центра видимой части, нормализация «ё», отступ на клавиатуру, прокручиваемый список |
